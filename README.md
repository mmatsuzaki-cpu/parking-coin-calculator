# 駐車場コイン計算

入庫時刻と現在時刻から、駐車料金と必要なコインの枚数を計算するツールです。

- 金コイン＝200円分 / 銀コイン＝100円分
- 金コインの在庫がないときは、金コイン1枚を銀コイン2枚に自動換算します
- 次に料金が上がる時刻も表示します

公開URL: https://mmatsuzaki-cpu.github.io/parking-coin-calculator/

## 料金ルール

| 時間帯 | 通常料金 |
|---|---|
| 昼間 8:00〜20:00 | 20分 / 200円 |
| 夜間 20:00〜翌8:00 | 60分 / 100円 |

無料特典は最大2時間・1人1日1回まで。
